Signpost for the old WordPress site (not part of the new website)

How to use: in the WordPress.com editor, add a new Custom HTML block at the top of the home page (and, if wanted, publish a short post with the same text), then paste the HTML from the grey box below. Before publishing, replace https://vates-journal.github.io/ (appears twice) with the real address.

Preview

Plain text version (for a post, Facebook or Twitter)

VATES has moved! The Journal of New Latin Poetry now lives at https://vates-journal.github.io/ — all issues free to read and download, plus how to contribute and contact us.

“This blog will remain online for the time being” is a suggestion — edit it to match what you actually plan to do with the old site.
